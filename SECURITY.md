# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The MANA OORU team takes security and privacy seriously. Because MANA OORU is an offline, client-side game that does not communicate with external analytics or telemetry servers, security focuses primarily on:
- Asset integrity and safe deserialization in Godot.
- Local system file-access boundaries.
- Safe offline execution.

If you discover a security vulnerability or malicious payload within an asset or dependency, please report it responsibly:
- Email: Contact the project maintainer directly or open a confidential security advisory on GitHub.
- Do not open a public issue for zero-day vulnerabilities.

We appreciate your efforts to keep our game and its players safe.
