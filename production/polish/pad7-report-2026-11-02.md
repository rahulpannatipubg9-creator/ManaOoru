## Planned device measurements (not yet performed)

`tools/performance/pad7_device_probe.gd` compares default quality at 60/90 FPS and reduced quality at 60/90 FPS. Reduced quality uses 50% 3D scale, 320 m view distance, 120 m simulation radius, 12 ambient actors, no real-time shadows, 25% effects.

It then samples scripted camera orbit, walking, city driving, real vehicle entry/exit, a separate continuous bridge-driving route and an idle endurance stage. The probe retains actual movement distance and blocked-driving time so a stationary vehicle cannot be reported as sustained travel. Physical touchscreen latency and all-district coverage remain separate manual checks.

The host runner retains raw Godot logs plus battery temperature, Android thermal-service state and process memory every 30 seconds. Example after installation:

```sh
python3 tools/performance/run_pad7_probe.py \
  --serial adb-2eed6023-7QkhoA._adb-tls-connect._tcp \
  --output production/polish/pad7-2026-11-02/comparison
```

For a longer selected-target run, add `--soak --fps 60 --drive-seconds 300 --idle-seconds 300` and use a new output directory. Maintain foreground focus throughout. Any script error, route obstruction or focus interruption must be disclosed when interpreting results.
