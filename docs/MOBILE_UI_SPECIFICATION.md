# Mobile UI Specification

## Current

- Landscape Android export.
- Responsive virtual joystick.
- Separate right-side camera gesture zone.
- ENTER shown only near an enterable vehicle.
- EXIT shown only while driving.
- RUN and JUMP controls in person mode.
- Reset/recover control for the active vehicle.

## Required next

- Safe-area insets for notches and system bars.
- Separate steering, throttle, and brake controls for driving.
- Configurable button placement and sensitivity.
- Pinch camera zoom.
- Pause/resume overlay.
- Graphics quality and audio settings.
- Touch cancellation and focus-loss tests on physical devices.
