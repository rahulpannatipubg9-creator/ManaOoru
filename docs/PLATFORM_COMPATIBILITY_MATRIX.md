# Platform Compatibility Matrix

| Platform | Current status | Evidence |
|---|---|---|
| macOS desktop | Working prototype | Godot desktop launches on Apple M1 |
| Windows desktop | Not tested here | Requires Windows test machine |
| Android phone | APK export available; device not tested | `builds/mana-ooru-debug.apk` |
| Android tablet | APK export available; device not tested | No ADB device connected |
| Controller | Not implemented | No controller action map yet |

The matrix records evidence only. It does not claim compatibility from an
export succeeding alone.
