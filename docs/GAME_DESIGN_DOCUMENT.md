# Godavarikhani Open World - Game Design Document

## Vision

MANA OORU is an offline, single-player, third-person exploration game set in a
recognizable Godavarikhani, Telangana environment. The first release focuses on
walking, entering and exiting a vehicle, driving, and discovering landmarks.
There is no combat or mission system in the first milestone.

## Player loop

1. Explore the city on foot.
2. Find a parked, enterable vehicle.
3. Enter it using the interaction prompt.
4. Drive to another location.
5. Exit safely and continue exploring.

## First playable milestone

- One low-poly person.
- One or more parked cars using one reusable vehicle scene.
- One bounded Godavarikhani environment.
- Person movement, sprint, jump, camera look, and vehicle proximity prompt.
- Exclusive control: only the person moves on foot; only the selected vehicle moves
  while driving; all other vehicles remain parked.
- Repeatable enter/drive/exit flow on desktop and Android UI.

## Future milestones

- Motorcycle controller using the same possession contract.
- Better modular buildings, local signs, autos, buses, and street props.
- Streamed districts and a full-screen map.
- Save/load, settings, audio controls, and accessibility options.
