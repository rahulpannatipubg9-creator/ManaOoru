# Historical shop reference import

Collected Mapillary observations are available offline through a Label3D research
panel at Bhaskar Bhavan (OSM way 599199178), visible within 100 m. The panel lists
Sri Sai Thirumala Kiranam, Sri Krishna Clinic, Fino Payment Bank, and Notary.
It carries the 11 June 2020 capture date, photographer, current-occupancy warning,
and explicit lack of verified individual shop bays. Men's Club Fashions is shown
only as another junction observation with its building unverified.

No business destination coordinates were guessed. The existing salmon/green
historical appearance reference remains active. Blender geometry is not imported
by this change. Restart the source project to load the new panel; existing exported
builds have not been regenerated.
